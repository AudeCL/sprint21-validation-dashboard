How to read this table

Solutioning status indicates the maturity of each user story and whether it is ready for stakeholder review.

○In Progress The Salesforce team is actively working on the user story, or is awaiting additional inputs before it can be completed. If validation is required, the item is not yet ready for review — validation will be requested once the solution reaches a more stable state.
◐Under Finalisation The Salesforce team is finalising the user story. If validation is required, reviewers may already start providing feedback, understanding that minor updates or clarifications may still be introduced before the user story is finalised.
●Finalised The Salesforce team has completed the user story. If validation is required, the item is ready for stakeholder review and approval.
✓Completed Validation was recorded as complete in ADO at the time of the extract. Pending means the validation is expected but not yet signed off; N/A means this validation type does not apply to the item.
